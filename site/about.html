About

Anime Fightings Simulators is maintained by an independent developer. It covers one Roblox game — Anime Fighting Simulator — across three pages: a working code list, a map and dimensions reference, and a tier list. The common thread is being straight about which parts are solid and which are not.

An independent, unaffiliated fan site

What this site is

A reference site for a single Roblox game, in three parts: the codes that currently work, where the world's areas and dimensions sit, and how Champions rank by stat. That is the whole scope. No news, no coverage of games nobody searched for, and nothing padded out to fill space.

It is not official. Anime Fightings Simulators has no connection to Roblox Corporation and none to the studio that makes the game. Nothing here is a statement from the developers, and codes listed here are ones the developers published, not ones this site invented.

How the code list gets built

Code lists rot fast, and most of them rot silently — a page last touched three weeks ago still presents itself as current. The method here is built around that problem.

  • Tier 1 — the developer’s own channels. The game’s Roblox page and the official group wall. One of those on its own is enough to put a code up, because it is first-hand rather than reported by someone else. Every row names which channel it came from.
  • Tier 2 — third-party code lists. A code from this tier goes up only when two independently maintained lists agree. One list alone is not enough. Where the two disagree, the disagreement is printed on the page rather than quietly resolved by picking a favourite.
  • Expired codes are not cross-checked. Most appear on one list only, so there is nothing to cross-check against. Instead, every row in the expired table carries the single source that listed it, so you can tell which rows have a second opinion behind them and which do not.
  • When no source has an answer — a level gate, an expiry timestamp, an error string — the page says so. It does not get filled with a plausible guess.
  • Claims that are reasoned rather than sourced are labelled as inference, with the reasoning shown.

The practical consequence: this page is sometimes shorter than the competition. A competitor listing thirty-seven working codes is usually listing years of dead ones. Five verified codes beat thirty-seven unverified ones.

What you will find here

Codes with conditions

Each code carries what is known about when it works — the version it shipped with, whether a gate exists, what happens on a second attempt.

Redemption steps

The actual in-game path, using the real interface labels, so it does not go stale when the layout shifts.

Honest unknowns

Gaps are marked on the page rather than papered over. You should be able to tell what is confirmed and what is not.

Corrections

Spot a dead code or a wrong number? Say so and it gets fixed. See the contact page.

How the site pays for itself

Advertising. Third-party vendors serve the ads on these pages and set cookies to do it. That arrangement is described in full in the privacy policy. It does not affect which codes appear on a page or in what order.
